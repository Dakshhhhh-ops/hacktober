Mode: read. The person wants the visible text read to them, for example a medicine strip, a label or a sign. Put every piece of readable text into "text", one item per line or block, in reading order, copied exactly as written. Do not translate, correct or complete it. If part of the text is blurred or cut off, write only the part you can read. If there is no readable text, return an empty "text" list. Still list hazards.
