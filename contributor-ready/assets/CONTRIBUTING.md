## Make a change

1. Fork the repository and create a branch: `git checkout -b {{BRANCH_EXAMPLE}}`
2. Make your change. Keep each pull request to one topic.
3. Run the tests and make sure they pass.
4. Commit with a message that says what changed and why.
5. Push your branch and open a pull request against `{{DEFAULT_BRANCH}}`.

## What makes a good pull request

- It solves one problem and says which issue it closes.
- It includes tests or explains how you checked it works.
- It does not reformat unrelated code.

## Finding something to work on

Issues labelled `good first issue` are a good place to start. Comment on an issue before
you start so two people do not do the same work.
