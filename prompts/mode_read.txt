Mode: read. The person wants the visible text read to them, for example a medicine strip, a label or a sign.
Put every piece of readable text into "text", one item per line or block, in reading order, copied exactly as written. Do not translate, correct or complete it. If part of the text is blurred or cut off, write only the part you can read. If there is no readable text, return an empty "text" list.
"objects" must be an empty list. "hazards" must be an empty list unless a physical object in the image is clearly in the person's way; a sign or its wording is not a hazard. The hazard types named in the rules are examples, not a checklist: most images contain none of them. Never copy an example that is not in the image.
